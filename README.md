# C/C++ 高程知识复习台 - 共享静态版

这是一个纯静态网站。它不依赖本机 Python 服务，默认只在浏览器内做结构检查。用户也可以手动开启第三方联网编译。

## 直接打开

双击 `index.html` 即可。所有学习进度保存在当前浏览器的 localStorage 中。

## 共享版能力

- 覆盖 lesson1-8 与期中综合梳理，共 101 张知识点卡和 86 张课件例题卡，数据版本 5。
- 课件例题严格按原文录入并标注课件页码，关键行高亮、逐条讲解；多程序例题分成独立代码块。
- 课件填空保留 `____`，18 张相关例题在代码下方单列“课件填空答案”。
- 按知识点分块，支持完全掌握、模糊、不明白三级状态。
- 完全掌握后折叠并移出待复习队列。
- 未掌握知识点按程度反复出现。
- 知识点卡只保留归纳、易错点与练习，不再放自编示例；例题卡只读展示课件原题与讲解。
- 在浏览器中检查代码关键结构，指出遗漏和常见错误。
- 默认关闭的 Judge0 联网编译：开启前必须确认代码和测试输入会发送给 ce.judge0.com。
- 联网编译可显示编译错误、运行输出、stderr、超时，并与期望输出或参考解输出比对。
- 一键复制 C++ 代码，粘贴到 VS2012、Dev-C++、Code::Blocks 或命令行 `g++` 验证。
- 支持搜索、筛选、今日复习统计和进度重置。

## 重要说明

默认结构判题不会执行 C++ 代码。只有用户主动开启“联网编译”并确认后，代码、测试输入和用于比对的参考解才会发送至第三方服务 `ce.judge0.com`；关闭开关后立即停止发送。

联网编译使用 Judge0 CE 的 C++ GCC 14.1.0 环境，并限制为 3 秒 CPU 时间、6 秒实际时间和 128 MiB 内存。第三方服务可能限流或暂时不可用，此时可以关闭联网编译继续使用结构检查，或复制代码到本地编译器。

学习进度只保存在用户自己的浏览器里，不会上传到服务器。更换浏览器、清理浏览器数据或使用无痕模式后，进度不会自动同步。

## 更新知识点

根目录修改 `data.js` 后，运行 `刷新共享版.ps1`，会同步最新数据、重建单文件分享版并重新生成 ZIP。
